革卦：泽火革——革故鼎新与顺天应人

卦序：第四十九卦
卦象：☱☲（兑上离下）
卦德：革、变革、革新
卦辞：己日乃孚，元亨利贞，悔亡。

1. 卦象与卦名训诂

1.1 卦象结构

革卦下离上兑。离为火，为明；兑为泽，为悦。泽中有火，水火相息，象征变革。又离火炎上，兑泽润下，二气不交则革，交则化生。

《象传》曰：泽中有火，革。君子以治历明时。

1.2 革字义训

  • 本义：皮革、去毛加工，引申为变革、革新。
  • 引申义：改革、革命、革除。
  • 易学义：去故取新，顺天应人。

《序卦传》曰：井道不可不革，故受之以革。

1.3 卦辞总义

己日乃孚，元亨利贞，悔亡。

  • 己日乃孚：至己日乃得诚信。己为天干之第六，象征变革成熟之时。
  • 元亨利贞：变革得正，则大通。
  • 悔亡：革而当，则悔恨消亡。

革卦强调：变革须待时而动，取得信任，方能成功。

2. 爻辞逐句疏解

2.1 初九

巩用黄牛之革。

初九阳刚居下，以黄牛之革巩固。象征变革之初宜稳固基础，不可轻动。

2.2 六二

己日乃革之，征吉，无咎。

六二阴柔中正，至己日乃变革。征行吉祥，无咎。象征变革须待时而行。

2.3 九三

征凶，贞厉，革言三就，有孚。

九三过刚不中，征行则凶，守正亦危。须变革之言三就而成，有诚信则可。象征变革须反复磋商。

2.4 九四

悔亡，有孚改命，吉。

九四阳刚近君，悔恨消亡。有诚信而改命，吉。象征变革改命成功。

2.5 九五

大人虎变，未占有孚。

九五阳刚中正，为卦主。大人之变革如虎之文彩变化，不待占卜而自信。象征王者革命，顺天应人。

2.6 上六

君子豹变，小人革面，征凶，居贞吉。

上六阴柔居极，君子如豹之变，小人仅革其面。征行则凶，居正则吉。象征变革之末，当安定守成。

3. 核心义理提炼

3.1 顺天应人

革之根本在于顺天应人。汤武革命，顺乎天而应乎人，是革之正义。

3.2 治历明时

《象传》言君子观革之象，当修订历法、明辨时序。变革须把握时机。

3.3 己日乃孚

变革不是突然之举，须经历酝酿、取得共识、建立信任，方可施行。

3.4 大人虎变

九五"大人虎变"揭示伟大变革者的自信与威严，其变光明正大、不言而信。

4. 现实映照

  • 政治改革：改革须顺民意、合时宜，取得广泛信任后再推行。
  • 企业转型：企业变革需先巩固基础、凝聚共识，不可冒进。
  • 个人蜕变：人的成长需要主动革新旧我，但也要循序渐进。

5. 发现与待延伸问题

5.1 本卦核心发现

  1. 革卦揭示变革的正义性：顺天应人、去故取新。
  2. "己日乃孚"强调变革成功的关键在于时机与信任。
  3. "大人虎变"与"君子豹变"区分了变革领导者的层次。

5.2 可延伸研究

  • 革卦与鼎卦的对待关系：革故鼎新，革是去旧，鼎是立新。
  • 革卦"汤武革命"思想与中国政治哲学中"革命"概念的演变。
