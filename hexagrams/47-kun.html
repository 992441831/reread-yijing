困卦：泽水困——困穷之时与致命遂志

卦序：第四十七卦
卦象：☱☵（兑上坎下）
卦德：困、困穷、围困
卦辞：亨，贞，大人吉，无咎，有言不信。

1. 卦象与卦名训诂

1.1 卦象结构

困卦下坎上兑。坎为水，为险；兑为泽，为悦。水在泽下，泽水已涸，象征困穷。又上悦下险，外虽悦而内实险，是困之象。

《象传》曰：泽无水，困。君子以致命遂志。

1.2 困字义训

  • 本义：困穷、围困、艰难。
  • 引申义：困苦、困顿、困厄。
  • 易学义：处困而不失其正，君子所以亨。

《序卦传》曰：升而不已必困，故受之以困。

1.3 卦辞总义

亨，贞，大人吉，无咎，有言不信。

  • 亨：困而能亨，在于心通。
  • 贞：守正。
  • 大人吉，无咎：大人处困，守正则吉而无咎。
  • 有言不信：困时言语难获信任，宜以行示人。

困卦强调：处困穷之时，大人当守正致命以遂其志，不以困而改节。

2. 爻辞逐句疏解

2.1 初六

臀困于株木，入于幽谷，三岁不觌。

初六阴柔居下，如臀困于枯木，入于幽谷。三年不得见。象征困之深、时之久。

2.2 九二

困于酒食，朱绂方来，利用亨祀，征凶，无咎。

九二阳刚居中，困于酒食之中。然朱绂（官服）方来，利于祭祀。征行则凶，守正则无咎。象征困中有望。

2.3 六三

困于石，据于蒺藜，入于其宫，不见其妻，凶。

六三阴柔不中，困于石、据于蒺藜，归家不见其妻。凶。象征困无所依。

2.4 九四

来徐徐，困于金车，吝，有终。

九四阳刚不中，来迟徐，为金车所困。有吝，然有终。象征困中渐进，终有成就。

2.5 九五

劓刖，困于赤绂，乃徐有说，利用祭祀。

九五阳刚中正，为卦主。如受劓刖之刑，困于赤绂。然徐而得脱，利于祭祀。象征王者处困，以诚感通。

2.6 上六

困于葛藟，于臲卼，曰动悔。有悔，征吉。

上六阴柔居极，困于藤蔓，危不安。动则有悔。然能悔悟而征，则吉。象征困极而知变。

3. 核心义理提炼

3.1 致命遂志

《象传》言君子处困之时，当舍命以遂其志。困厄不能夺其志，是困卦之大义。

3.2 困而能亨

困卦卦辞言"亨"，说明困厄在于外，亨通在于心。心志不屈，则困不能困。

3.3 有言不信

困时言语难信，君子当以行动、以祭祀（诚心）感通，而非空谈。

3.4 大人与小人之困

大人处困能守正遂志，小人处困则怨天尤人。困是人格的试金石。

4. 现实映照

  • 逆境坚守：真正的强者不是不遇困，而是处困不改其志。
  • 信任危机：困境中少言多做，以实际成果重建信任。
  • 创业艰难：创业者常处困中，能坚持使命者终能突围。

5. 发现与待延伸问题

5.1 本卦核心发现

  1. 困卦揭示困厄是人生常态，关键在于"致命遂志"。
  2. "有言不信"说明困境中行动比言语更有力量。
  3. 困卦各爻展示困的不同层次，终以悔悟征吉收束。

5.2 可延伸研究

  • 困卦与坎卦、蹇卦在"困/险/难"主题上的比较。
  • 困卦"致命遂志"与儒家"杀身成仁"、斯多葛主义坚忍哲学的对话。
