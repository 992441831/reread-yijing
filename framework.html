研究框架与方法说明

本文档说明本项目的研究定位、分析框架、专题方向、写作模板与基本守则，为所有报告提供统一的方法论基础。

一、项目定位与研究宗旨

1.1 核心目标

  • 以现代学术方法与数字人文工具重读《易经》。
  • 打通“文本—象数—义理—历史—比较哲学”五重视角。
  • 产出系列专题报告，服务于个人研习、论文写作与哲学对话。

1.2 研究原则

  1. 文本优先：一切阐释必须回到原文、原注与原语境。
  2. 方法多元：兼容文献学、哲学分析、统计学、概念史与比较研究。
  3. 可验证：重要结论须注明出处、版本与推理链条。
  4. 可迭代：每份报告可沉淀为后续研究的模块或数据源。

二、《易经》总体分析框架

2.1 文本层：经书结构

层级 内容 关键问题
经（Text） 六十四卦卦符、卦名、卦辞、爻辞 文本来源、层累形成、巫史传统
传（Commentaries） 《十翼》：彖、象、文言、系辞、说卦、序卦、杂卦 战国至汉代的哲学化阐释
注疏（Exegesis） 王弼、韩康伯、孔颖达、朱熹、来知德等 各时代如何重释易理
术数（Divination） 揲蓍法、纳甲、梅花易数、奇门遁甲 象数系统与占卜实践

2.2 象数层：符号与推演

  • 阴阳：从“— / --”到二元范畴的哲学化。
  • 八卦：乾、坤、震、巽、坎、离、艮、兑的象征体系。
  • 六十四卦：卦序（通行本 vs. 帛书本 vs. 竹简本）、卦变、错综、往来。
  • 爻位：当位、相应、乘承、往来、进退、得失。
  • 大衍之数：五十、四十八、十有八变而成卦的数学结构。

2.3 义理层：核心概念谱系

天 ─ 道 ─ 命 ─ 性 ─ 情 ─ 欲
│
├─ 易：变易、不易、简易
├─ 生生：天地之大德曰生
├─ 时中：与时偕行、得中得正
├─ 忧患：亢龙有悔、惧以终始
├─ 感通：寂然不动，感而遂通
└─ 象意：立象以尽意，得意而忘象

2.4 历史层：生成与流变

  1. 巫易时代（商周）：卜筮原始形态。
  2. 史易时代（西周至春秋）：卦爻辞编纂，史官文化。
  3. 哲易时代（战国）：诸子借易立说，《易传》形成。
  4. 玄易时代（汉魏）：象数易学、王弼玄学义理。
  5. 理易时代（宋明）：程朱理学、陆王心学与易学。
  6. 现代易学：考古新材料（马王堆、上博简、清华简）、海外汉学。

2.5 比较层：跨文明对话

  • 与道家：老庄的“道”与《易》之“道”的异同。
  • 与儒家：孔子“五十以学易”、孟子“尽心知性知天”。
  • 与佛学：华严“理事无碍”与易之象数结构。
  • 与西方哲学：赫拉克利特“流变”、怀特海“过程哲学”、莱布尼茨二进制。
  • 与现代科学：系统论、复杂性科学、量子互补与阴阳模型。

三、专题研究方向（报告主题池）

3.1 单卦深读

每卦一份微型报告，固定结构：

  1. 卦象与卦名训诂
  2. 卦辞、爻辞逐句疏解
  3. 彖传、象传、文言（如适用）阐释
  4. 核心义理提炼
  5. 历史案例或现实映照
  6. 与相关卦的比较（错、综、复、杂）

3.2 主题贯通研究

  • 吉凶悔吝吝厉的伦理语法学
  • “时”的哲学：待时、趋时、时中
  • “位”的政治哲学：君臣、上下、进退
  • “象”的认识论：观物取象与符号思维
  • 《易传》中的宇宙生成论
  • 《易经》与先秦诸子的互文

3.3 方法实验

  • 文本计量：卦爻辞高频词、语义网络
  • 版本对照：通行本 / 帛书《周易》/ 阜阳简 / 海昏侯简
  • 可视化：卦序图、卦变网络、概念共现图
  • 编程模拟：大衍揲蓍、卦变推演、随机占断对照

四、报告写作模板

每份报告建议按以下章节组织：

# 报告标题

## 1. 问题缘起
- 研究动因与核心问题

## 2. 文献基础
- 核心文本、版本、注疏

## 3. 分析框架
- 采用的本报告视角（文本/象数/义理/历史/比较）

## 4. 主体论证
- 分层推进、引证并行

## 5. 发现与结论
- 主要观点、限制与可延伸之处

## 6. 附录
- 卦图、表格、代码、延伸阅读

五、参考版本与工具

5.1 推荐文本

  • 阮刻本《十三经注疏·周易正义》
  • 朱熹《周易本义》
  • 高亨《周易古经今注》《周易大传今注》
  • 黄寿祺、张善文《周易译注》
  • 马王堆帛书《周易》（陈鼓应、廖名春整理本）

5.2 数字工具

  • 文本处理：Python（pandas, jieba, networkx）
  • 可视化：matplotlib, ECharts, D3.js
  • 版本控制：Git
  • 知识管理：Obsidian / Markdown 双链

六、研究守则

  1. 不将《易经》简化为占卜手册，也不神化其为万能体系。
  2. 区分“经”“传”“注”“术”四个层次，避免时代错置。
  3. 对考古新材料保持敏感，对过度推测保持警惕。
  4. 在跨文明比较中，先做“同情的理解”，再做“批判的辨析”。

本框架为活文档，将随研究深入不断修订。
