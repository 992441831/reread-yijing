# 履卦：天泽履——践行之道与礼行天下

**卦序**：第十卦  
**卦象**：☰☱（乾上兑下）  
**卦德**：履、践行、礼行  
**卦辞**：履虎尾，不咥人，亨。

---

## 1. 卦象与卦名训诂

### 1.1 卦象结构

履卦下兑上乾。兑为泽，为悦；乾为天，为健。天在上，泽在下，象征尊卑有序、各安其位。又乾为刚健，兑为和顺，以和悦履刚健，是践履之道。

《象传》曰：上天下泽，履。君子以辨上下，定民志。

### 1.2 履字义训

- **本义**：鞋、踩踏、践行。
- **引申义**：履行、实践、礼仪。
- **易学义**：循礼而行、谨慎践履。

《序卦传》曰：物畜然后有礼，故受之以履。履者，礼也。

### 1.3 卦辞总义

> 履虎尾，不咥人，亨。

- **履虎尾**：践履在老虎尾巴之后，比喻处境危险。
- **不咥人**：老虎不咬人。
- **亨**：以礼而行，虽危亦亨。

履卦强调：以礼、以敬、以柔践行，即使身处险境，也能化险为夷。

## 2. 爻辞逐句疏解

### 2.1 初九

> 素履，往无咎。

初九阳刚在下，以朴素之心践履其道，前往无咎。素履即本乎素愿，不尚浮华。

### 2.2 九二

> 履道坦坦，幽人贞吉。

九二阳刚得中，所行平坦。如幽隐之人守正，不慕荣利，故吉。

### 2.3 六三

> 眇能视，跛能履，履虎尾，咥人，凶。武人为于大君。

六三阴柔不中，才弱而志刚，如盲者视、跛者行。强行践履危地，故致虎咥之凶。然若能如武人效忠大君，亦有一线转圜。

### 2.4 九四

> 履虎尾，愬愬终吉。

九四近君多惧，如履虎尾。然能恐惧修省、谨慎自持，终得吉祥。

### 2.5 九五

> 夬履，贞厉。

九五阳刚得中居尊，刚决而履。虽得正，但过于刚断，故有危厉。警示居高位者不可专断独行。

### 2.6 上九

> 视履考祥，其旋元吉。

上九履之终，回顾所行，考察吉凶祸福，然后返回正道，故获元吉。

## 3. 核心义理提炼

### 3.1 履即礼

《序卦传》明言：履者，礼也。履卦将践行与礼仪合一，强调行为须合乎规范。

### 3.2 以敬行险

履虎尾而不咥人，关键在于敬。心存敬畏、行为合礼，虽处险地亦无咎。

### 3.3 辨上下，定民志

君子观履卦，当知分辨尊卑上下，使民心安定。礼的核心功能即在于建立秩序。

### 3.4 回顾与修正

上九视履考祥，强调实践之后的反思与修正。行而后思，方能元吉。

## 4. 现实映照

- **职场**：新人入职如履虎尾，宜谦虚守礼、谨慎行事。
- **公共生活**：礼仪不是形式主义，而是降低冲突、建立信任的机制。
- **个人修养**：以礼自律，以敬待人，是履卦的核心实践。
