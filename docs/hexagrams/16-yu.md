# 豫卦：雷地豫——豫乐之和与防逸之道

**卦序**：第十六卦  
**卦象**：☳☷（震上坤下）  
**卦德**：豫、安乐、豫备  
**卦辞**：利建侯行师。

---

## 1. 卦象与卦名训诂

### 1.1 卦象结构

豫卦下坤上震。坤为地，为顺；震为雷，为动。雷出于地，阳气奋发，万物悦乐，故为豫象。又上动下顺，顺以动，故天地如之，而况建侯行师乎。

《象传》曰：雷出地奋，豫。先王以作乐崇德，殷荐之上帝，以配祖考。

### 1.2 豫字义训

- **本义**：安乐、悦乐、和豫。
- **引申义**：预备、豫谋、犹豫。
- **易学义**：顺时而动，物情悦乐。

《序卦传》曰：有大而能谦必豫，故受之以豫。

### 1.3 卦辞总义

> 利建侯行师。

- **利建侯**：豫乐之时，人心和顺，利于封建诸侯、分封治理。
- **行师**：亦利于兴师动众，因上下悦而从命。

豫卦强调：安乐和顺之世，利于聚众成事，但亦需防逸豫之失。

## 2. 爻辞逐句疏解

### 2.1 初六

> 鸣豫，凶。

初六阴柔居下，与九四相应，因上之豫而鸣。自鸣得意，故凶。象征沉溺于豫乐而失正。

### 2.2 六二

> 介于石，不终日，贞吉。

六二柔顺中正，操守坚如介石。见几而作，不终日而悟，守正得吉。象征在豫中能警觉。

### 2.3 六三

> 盱豫，悔。迟有悔。

六三阴柔不中，媚上求豫，瞻望不安。此已可悔，若迟疑不改，悔更甚。象征求乐不当。

### 2.4 九四

> 由豫，大有得。勿疑，朋盍簪。

九四阳刚得正，为豫卦之主。众阴依之而得豫，故大有得。不疑而信，朋友如簪之合聚。象征豫乐之源在正。

### 2.5 六五

> 贞疾，恒不死。

六五柔顺居尊，乘刚于九四之下，故有疾苦。然居中得正，故恒不死。象征居尊处豫不可无戒。

### 2.6 上六

> 冥豫，成有渝，无咎。

上六处豫之极，昏暗于豫乐。若能觉悟改易，则可无咎。象征溺豫而知变。

## 3. 核心义理提炼

### 3.1 豫乐需以正

豫卦之安乐，源于顺以动、以德服众。初六"鸣豫"、六三"盱豫"皆以邪求乐，故凶悔。

### 3.2 见几而作

六二"介于石，不终日"揭示豫中当有警觉，见微知著，及时守正。

### 3.3 作乐崇德

《象传》言先王因豫而作乐，以崇敬其德，祭祀上帝与祖考。说明豫乐当升华于礼乐文明，而非纵欲。

### 3.4 防逸豫之失

豫乐之世易生骄逸。上六"冥豫"警示耽溺安乐必致昏昧，唯知变可无咎。

## 4. 现实映照

- **娱乐文化**：现代社会娱乐泛滥，真正的"豫"应崇德而非纵欲。
- **组织激励**：企业奖励机制应建立在正道基础上，避免"鸣豫"式的虚荣与"盱豫"式的谄媚。
- **个人生活**：享受安乐时保持"介于石"的清醒，防止乐极生悲。

## 5. 发现与待延伸问题

### 5.1 本卦核心发现

1. 豫卦揭示安乐的双重性：和顺之豫可聚众成事，纵欲之豫则致凶悔。
2. 六二"介于石，不终日"是豫中知几守正的典范。
3. "作乐崇德"说明豫乐应上升为礼乐文明与道德实践。
